A one-star review of the Moon — 119 characters, winner-take-all entry for
[The Moon Gets One Star](https://make.fun/bounty/u-eager-stork-81-9647-the-moon-gets-one-star-768236e5)
($2, deadline 26 Nov 2026 21:45 WIB).

> One star. The Moon shows up late, never replies, and just stares all night. Worst roommate ever. Would not orbit again.

Eight candidate lines were drafted and scored on humour, real-review feel, and
originality — see [VARIANTS.md](VARIANTS.md). This one won: it reads exactly like
a frustrated tenant's review, and the Moon just happens to be the roommate.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/path/to/output python3 main.py
```

Writes `review.txt` (byte-identical to the entry above, no trailing newline)
into the output directory. Without `MAKEFUN_OUTPUT_DIR` it falls back to
`/output`. The program only creates the output directory if needed and never
writes anything into the repo. Re-running produces the exact same file.
